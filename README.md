# Password Strength Checker

A simple cybersecurity project built using Flask, HTML, CSS, and JavaScript to analyze password strength in real time.

## Features
- Checks password strength
- Detects uppercase, lowercase, numbers, and symbols
- Detects common passwords
- Shows security suggestions
- Real-time password analysis
- Responsive dark UI

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript

## Project Structure

```bash
password-checker/

│
├── templates/
│   └── index.html
│
├── common_passwords.txt
└── README.md
```

## Installation

1. Clone the repository
git clone https://github.com/Rohit820911/Password_strength_checker.git
2. Move into the project folder
cd Password_strength_checker
3. Install Flask
pip install flask
4. Run the application
python app.py
5. Open in browser
http://127.0.0.1:5000
